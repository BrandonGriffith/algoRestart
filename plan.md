## Conventions for future additions

- Keep each problem in its own folder with JavaScript, Python, and TypeScript solutions and tests.
- Use `snake_case` Python filenames and identifiers; keep files clean under default Pylint checks.
- Test boundaries and mutation behavior; include multiple approaches when they teach useful trade-offs.
